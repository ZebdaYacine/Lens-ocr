# SinLens OCR

Run the local OCR script against a PDF, image, or HTTP(S) URL:

```powershell
python -u main.py "http://192.168.99.103:3486/Instructions/2024/P1-12-2024.jpg"
```

The result is saved in a folder named after the document, with one `.txt`
file and an `ocr.log` file. The pipeline selects the highest-scoring OCR
orientation and reconstructs the page layout from line coordinates.

Install the Python dependencies with:

```powershell
python -m pip install -r requirements.txt
```

## Visual line selector

Start the local UI with:

```powershell
python -m http.server 8080 --directory ui
```

Open `http://localhost:8080`. Import the document image and, optionally, the
`.txt` generated by the OCR script. Drag over readable lines, edit or uncheck
any line in the right panel, and click an imported OCR line to assign it to the
active box. Export a TXT file with the selected lines placed at their original
relative positions.

The **Convert to TXT** button offers both **Full document** and **Selected
zone**. Full document exports the imported OCR text unchanged; Selected zone
exports only the checked line boxes with layout spacing preserved.

## SinLens desktop UI

Run the Windows desktop interface with:

```powershell
python ui.py
```

It provides the same Lens-style document viewer without a browser. The center
is divided into an **Input** document area and an **Output** results area.
Import an image/PDF from a local file or HTTP(S) URL, rotate or zoom it, draw
readable zones, then use **Convert to TXT** for the full document or the
selected zones. Conversion runs the OCR pipeline directly and saves
automatically: beside a local source file, or in the user's `Downloads` folder
for a remote URL. No save-location dialog is shown.

The desktop UI also includes **Clear** and **Remove document** controls. A
conversion progress dialog stays visible until `main.py` finishes; removing a
document only clears it from the interface and does not delete the source file.
After conversion, **Save result** saves the displayed TXT again at the same
automatic path, or opens a save-location dialog when you want to choose a
different folder. The desktop interface uses a light theme with standard
button colors.

Use `--output` to choose the destination directory, `--keep-images` to retain
the selected page images, and `--help` to see all available options.
